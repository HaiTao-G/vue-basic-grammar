关键代码

1. actions 里直接改（对比 Vuex 要 commit）

actions: {
  add(text) {
    this.list.push({ text, done: false })   // 直接改，没有 mutation
  },
  toggle(item) {
    item.done = !item.done
  }
}

2. 异步 action：async/await 直接用

async loadFromServer() {
  this.loading = true
  // 真实项目：const res = await axios.get('/api/todos')
  await new Promise(r => setTimeout(r, 1000))
  this.list = [ ... ]
  this.loading = false
}

// 组件里调用，返回的是 Promise，可以 await 或 .then
await todo.loadFromServer()

3. 三个好用的自带方法

方法 作用 示例
$patch 一次修改多个数据（只触发一次更新） store.$patch({ a: 1, b: 2 }) 或传函数
$reset 把 state 恢复到初始值 store.$reset()
$subscribe 订阅 state 变化（做日志、自动保存草稿） store.$subscribe((m, state) => {}) 
// $patch 的两种用法
store.$patch({ filter: 'done', loading: false })        // 传对象
store.$patch((state) => { state.list.forEach(t => t.done = true) }) // 传函数（推荐）

注意：$reset 只对"选项式"定义的 store 有效；用 setup 函数式定义的 store 没有这个方法， 需要自己写一个重置的 action。
