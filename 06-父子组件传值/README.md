## 三、核心概念速查

### 1. 为什么要传值

组件是**独立的作用域**：子组件写在自己的 `data` 里，父组件的数据它默认一个都访问不到。
所以数据必须通过 props 显式"往下传"。

### 2. 两条主线（记这句口诀就够）

> **数据向下流（props），事件向上抛（$emit）。**

| 方向     | 手段                     | 写法                                                   |
| -------- | ------------------------ | ------------------------------------------------------ |
| 父 → 子  | props（自定义属性）      | 父：`<child :msg="parentMsg" />`<br />子：`props: ['msg']` |
| 子 → 父  | $emit（自定义事件）      | 子：`this.$emit('change', 新值)`<br />父：`<child @change="handler" />` |

### 3. 为什么要绕这一圈

因为 **props 是只读的（单向数据流）**。子组件不能直接修改父传下来的数据，
否则数据从哪来、被谁改了就说不清了。正确做法是：**子组件把"想改成什么"告诉父组件，
由父组件自己去改。**

### 4. props 命名：定义用驼峰，使用用连字符

- JS 里定义：`props: ['userName']`
- HTML 里传值：`<my-comp :user-name="name" />`

原因是 HTML 属性名**大小写不敏感**，`userName` 会被浏览器变成 `username`，对不上。

## 四、易错点提醒

1. **HTML 里要用连字符**（`user-name`），不能写 `userName`，否则子组件收不到。
2. **子组件不能直接改 props**，`this.msg = xxx` 会触发 Vue 警告，数据也不会真正生效。
3. **对象/数组类型的 `default` 必须写成函数**：`default: () => []`，写 `default: []` 会导致多个实例共享同一个数组。
4. **组件名也用连字符**（`<my-child>`），别写 `<myChild>`，DOM 模板里同样大小写不敏感。
5. **`$emit` 的事件名建议用连字符**（`add-item`），父组件用 `@add-item` 监听。
6. 父子通信能靠 props / $emit 解决的，就不要用 `$parent` / `$children`（耦合太高，难维护）。
