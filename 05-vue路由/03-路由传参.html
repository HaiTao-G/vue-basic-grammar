一、query 传参 地址形如 /detail?id=1&kw=vue，参数在 ? 后面

二、params 传参 地址形如 /user/100，参数是路径的一部分，必须在 routes 里用 :xxx 占位

三、query 与 params 的区别

对比项 query params
地址长相 /detail?id=1 /user/100
取值方式 this.$route.query.id this.$route.params.id
路由规则要求 无需配置 必须写 path: '/user/:id'
跳转写法要求 path 或 name 都行 必须用 name
刷新后是否保留 保留 hash 模式下会丢
实践建议：需要刷新后仍然存在的参数（筛选条件、翻页页码、搜索词）用 query； 只是临时传递、不希望暴露在地址栏的参数用 params。
