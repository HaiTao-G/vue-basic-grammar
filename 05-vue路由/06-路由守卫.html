守卫的三种写法：
1. 全局守卫 router.beforeEach((to, from, next) => {}) —— 最常用，登录拦截就靠它
2. 路由独享守卫 { path:'/x', beforeEnter(to, from, next){} } —— 只对这条路由生效
3. 组件内守卫 beforeRouteEnter / beforeRouteLeave —— 写在组件里（离开页面时提醒保存草稿常用）
