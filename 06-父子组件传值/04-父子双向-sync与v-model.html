父子"双向"：.sync 与 v-model

前面讲的是：父传子用 props，子传父用 $emit。这样一来"子组件想改父组件的值"要写两段代码。
Vue 提供了两个语法糖把这两步合成一步写：.sync 和组件上的 v-model。
注意：本质没变，底层依然是 props + $emit，"单向数据流"这条底线没有被打破。

一、.sync 修饰符

父组件里的 title = {{ title }}

简写（推荐）：

<my-panel :title.sync="title"></my-panel>

完整写法（等价）：

<my-panel :title="title"
          @update:title="title = $event"></my-panel>

二、组件上的 v-model

父组件里的 text = {{ text }}

简写：

<my-input v-model="text"></my-input>

完整写法（等价）：

<my-input :value="text"
          @input="text = $event"></my-input>

三、两个语法糖对比

语法糖 本质是 子组件要做什么
:x.sync="val" :x="val" @update:x="val = $event" $emit('update:x', 新值)
v-model="val" :value="val" @input="val = $event" props 声明 value，然后 $emit('input', 新值)

记忆点：.sync 靠 update:xxx 事件，v-model 靠 input 事件 + value prop。 Vue 3 里 v-model 的约定改成了 modelValue / update:modelValue，本项目是 Vue 2，按上面的写。
