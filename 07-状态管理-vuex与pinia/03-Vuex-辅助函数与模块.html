Vuex 辅助函数与模块化

问题 1：每次都要写 this.$store.state.xxx、this.$store.commit('XXX') 太啰嗦。
解决：用 mapState / mapGetters / mapMutations / mapActions 把它们直接映射成组件的计算属性和方法。
问题 2：所有数据塞在一个 store 里，项目一大就乱了。
解决：拆成 modules（模块），每个模块管自己的一块。
根 store（演示 mapState / mapGetters / mapMutations）

用户名（mapState）：{{ userName }} ｜ 问候语（mapGetters）：{{ welcome }} ｜ 购物车件数（根 getters 读模块 state）：{{ cartCount }}

上面这个按钮调用的是 ...Vuex.mapMutations(['SET_USER_NAME']) 映射出来的方法， 写起来就像调用本地方法一样，看不到 $store。

模块化的购物车模块（cart，带命名空间）

辅助函数怎么用

// 写法一：数组，名字和 store 里一致
computed: {
  ...Vuex.mapState(['userName']),
  ...Vuex.mapGetters(['itemCount', 'totalPrice'])
},
methods: {
  ...Vuex.mapMutations(['ADD_ITEM']),
  ...Vuex.mapActions(['addItemAsync'])
}

// 写法二：对象，可以顺便改名
computed: {
  ...Vuex.mapState({
    name: 'userName',        // this.name 就是 store 里的 userName
    count: 'itemCount'
  })
}

模块 + 命名空间怎么用：

// 1. 定义模块时加上 namespaced: true
const cart = {
  namespaced: true,
  state: { items: [] },
  getters: { total: state => ... },
  mutations: { ADD(state, item) {...} },
  actions: { addAsync({ commit }, item) {...} }
}

// 2. 注册到 store 的 modules 里
new Vuex.Store({ modules: { cart } })

// 3. 组件里用 createNamespacedHelpers 生成带前缀的辅助函数
const helpers = Vuex.createNamespacedHelpers('cart')
computed: {
  ...helpers.mapState(['items']),
  ...helpers.mapGetters(['total'])
}
// 不加命名空间的调用方式（对比）：
// this.$store.commit('cart/ADD', item)   注意有 cart/ 前缀
辅助函数 映射到 原来要写
mapState computed this.$store.state.x
mapGetters computed this.$store.getters.x
mapMutations methods this.$store.commit('X')
mapActions methods this.$store.dispatch('X')

记法：state / getters 映射成 computed（因为它们是"读值"）， mutations / actions 映射成 methods（因为它们是"执行动作"）。
