子传父：$emit 自定义事件

场景：子组件里点了个按钮，需要让父组件的数据发生变化。
为什么不能直接改：props 是只读的，子组件不能碰父组件的数据。
办法：子组件用 this.$emit('事件名', 要传的数据) "喊一声"， 父组件用 @事件名="处理函数" 接住。
口诀：事件向上抛。

例 1：子组件点按钮 → 父组件改数据（不带参数）

父组件里的计数器 total = {{ total }}

数据流：子组件 $emit('add')  ➜  父组件 @add="total += 1"  ➜  total 变化  ➜  页面更新

例 2：子组件把输入内容交给父组件（带参数）

父组件收到的留言列表：

  • {{ item }}

（还没有留言，在上面的子组件里输入并提交试试）

数据流：子组件 $emit('submit', 输入内容)  ➜  父组件 @submit="addComment"  ➜  addComment(内容) 把它推进数组

要点小结

环节 写在谁身上 代码
抛事件 子组件 this.$emit('submit', 数据)
接事件 父组件 <add-comment @submit="addComment">
改数据 父组件 addComment(val) { this.comments.push(val) }

提醒：事件名建议用连字符（add-item），父组件用 @add-item 监听； 因为是自定义事件，名字随便起，但两边必须完全一致。
