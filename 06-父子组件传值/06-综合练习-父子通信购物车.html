综合练习：父子通信购物车

设计原则：数据放在"共同祖先"里（这里是父组件），子组件只负责展示和"报告用户操作"。
通信路径：商品列表子组件 --（add-to-cart 事件）--> 父组件改数据 --（props）--> 购物车子组件重新渲染。

商品列表 共 {{ products.length }} 件

子组件内部：this.$emit('add-to-cart', this.item)
父组件监听：<product-item @add-to-cart="addToCart">

当前数据在父组件里

products（商品）= {{ products.length }} 条

cart（购物车）= {{ cart.length }} 种商品，共 {{ totalCount }} 件

打开 Vue Devtools 或控制台可以看到：子组件里没有商品和购物车数据， 它们全在父组件里，子组件只拿到"自己要显示的那一部分"。

购物车

子组件内部：this.$emit('remove', index) / this.$emit('change-count', index, delta)
父组件监听并修改自己的 cart 数组

本页用到的父子通信方式回顾

通信 方式 代码位置
父 → 子 props 传数据 :item="p" / :items="cart"
子 → 父 $emit 抛事件 $emit('add-to-cart', item)
谁改数据 永远是父组件改 addToCart() / removeItem() / changeCount() / clearCart()
派生计算 父组件用 computed totalCount / totalPrice

延伸思考：如果以后商品列表和购物车是两个"平级"的兄弟组件， 而数据要共享，怎么办？—— 一般把数据提到它们共同的父组件里（就是本页的做法）； 项目更大时，再考虑 Vuex / 事件总线。
