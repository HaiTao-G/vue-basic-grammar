Pinia 入门：state 与 getters

Pinia 是 Vue 官方新一代状态管理库（Vue 3 默认推荐）。它同样支持 Vue 2.7， 在 Vue 2 项目里也能用。
和 Vuex 比，最大的不同：没有 mutations。改数据直接写在 actions 里，简单直接。
本页只讲"读"：state 存数据，getters 是计算属性。

仓库（store）当前的样子

state: {
  count: {{ counter.count }},
  user: { name: "{{ counter.user.name }}" }
}
getters: { doubleCount: {{ counter.doubleCount }} // count × 2 }

直接用 counter.xxx 就能读，不需要 $store.state.xxx 这么长。

两个兄弟组件，共享同一个 store

defineStore 的两种写法

写法一：选项式（和 Vuex 很像，上手快）

const useCounterStore = Pinia.defineStore('counter', {
  state: () => ({ count: 0 }),
  getters: {
    doubleCount: (state) => state.count * 2
  },
  actions: {
    inc() { // 注意：直接用 this 改，没有 mutation 这一层
      this.count++
    }
  }
})

写法二：组合式（setup 风格，更自由，写起来像写组件）

const useUserStore = Pinia.defineStore('user', () => {
  // 用 Vue 2.7 内置的 Composition API
  const name = Vue.ref('海涛')
  const isVip = Vue.ref(true)
  const title = Vue.computed(() => isVip.value ? 'VIP' : '普通')

  function setName(v) { name.value = v }

  // 必须 return 出去，外面才能用
  return { name, isVip, title, setName }
})

两种写法效果一样，选一种团队习惯的即可。选项式更接近 Vuex 的思维，组合式更灵活、类型提示更好。

在组件里怎么用

// 1. 先安装插件、创建 pinia 实例、挂到 Vue 上
Vue.use(Pinia.PiniaVuePlugin)
const pinia = Pinia.createPinia()
new Vue({ el: '#app', pinia })

// 2. 组件里（选项式组件用 setup 选项）
Vue.component('my-comp', {
  setup() {
    const counter = useCounterStore()
    // ⚠️ 解构要用 storeToRefs 包一层，否则丢失响应式
    const { count, doubleCount } = Pinia.storeToRefs(counter)
    return { count, doubleCount, counter }
  },
  template: `<div>{{ count }} / {{ doubleCount }}</div>`
})
最常见的坑：
const { count } = counter ❌ —— 这样拿到的是一个普通数字，之后 store 变了页面不会更新。
const { count } = Pinia.storeToRefs(counter) ✅ —— 保持响应式。
（actions 不需要 storeToRefs，它们本来就是方法；state 和 getters 才需要。）
