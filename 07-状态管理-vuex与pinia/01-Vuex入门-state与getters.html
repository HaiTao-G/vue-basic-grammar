Vuex 入门：state 与 getters

要解决的问题：下面两个组件是"兄弟"关系，它们需要显示同一份数据。 按 06 章学的父子传值，得把数据提到父组件、再分别传下去，很麻烦。
Vuex 的思路：把这份数据放进一个"公共仓库"（store），两个组件都直接从仓库里取。
本页只讲"读"：state 存数据，getters 是仓库里的计算属性。

仓库（store）当前的样子

state: {
  count: {{ $store.state.count }},
  user: { name: "{{ $store.state.user.name }}", vip: {{ $store.state.user.vip }} }
}

getters（仓库的计算属性）：

doubleCount: {{ $store.getters.doubleCount }}   // count × 2
vipText: "{{ $store.getters.vipText }}"   // 根据 vip 状态返回文案

两个兄弟组件，共享同一份数据

两个组件都从同一个 store 取数据 ↑↑ 数据完全一致

知识点

概念 作用 组件里怎么读
state 存放共享数据（相当于组件的 data） this.$store.state.count
getters 对 state 做派生（相当于组件的 computed），有缓存 this.$store.getters.doubleCount

小技巧：getters 的第二个参数就是其他 getters，可以互相引用； 组件里也可以用 this.$store 在控制台手动查看整个仓库。
