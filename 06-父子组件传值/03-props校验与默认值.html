props 校验与默认值

前面用数组写 props 只能声明"名字"。真正写项目时，要用对象写法给每个 prop 加上 类型、是否必填、默认值等约束，这样传错了 Vue 会在控制台提醒你。
建议现在就养成用对象写法的习惯。

完整的 props 写法长这样

props: {
  // 基础类型校验 + 必填
  title:   { type: String, required: true },

  // 默认值
  likes:   { type: Number, default: 0 },

  // ⚠️ 对象/数组的默认值必须写成函数！
  tags:    { type: Array,  default: () => [] },

  // 自定义校验器：返回值是 false 就报警告
  status:  { type: String, default: "normal",
             validator: (v) => ["normal", "vip"].includes(v) }
}
选项 作用
type 规定类型：String / Number / Boolean / Array / Object / Function
required 是否必填，没传会报警告
default 没传时的默认值（对象/数组必须用函数返回）
validator 自定义校验函数，返回 false 触发警告

看效果：三个实例，传参各不相同

请按 F12 打开控制台，能看到类似这样的提示： 

[Vue warn]: Invalid prop: type check failed for prop "likes". Expected Number, got String.
[Vue warn]: Invalid prop: custom validator check failed for prop "status".

注意：校验只在开发环境提醒，不会阻断代码运行——页面照常渲染， 所以很多人忽略了控制台的黄色警告。养成看控制台的习惯。

重点提醒：对象 / 数组的 default 必须用函数

❌ 错误写法

tags: { type: Array, default: [] }

所有使用该组件的实例会共享同一个数组，一个地方 push，别的地方也变了。

✅ 正确写法

tags: { type: Array, default: () => [] }

每次创建实例都调用函数拿到新数组，实例之间互不影响。
