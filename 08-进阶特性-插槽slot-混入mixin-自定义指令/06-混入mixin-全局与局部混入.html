06 - 混入（Mixin）：逻辑复用与选项合并策略

💡 什么是 Mixin？
混入（Mixin）提供了一种非常灵活的方式，用来分发 Vue 组件中的可复用逻辑功能。
一个混入对象可以包含任意组件选项（data、methods、mounted、computed 等）。当组件使用混入对象时，所有混入对象的选项将被“混合”进入该组件本身的选项中。

✨ 交互演示：两个独立组件复用同一套“分页与加载逻辑 (paginationMixin)”

📖 选项合并规则（面试核心必考点）

当组件自身的属性与 Mixin 产生命名冲突时，Vue 遵循以下确定规则：

选项类型 合并策略 谁生效 / 谁优先
data 数据对象 在内部进行递归合并。发生键名冲突时： 以组件自身数据优先
生命周期钩子
(created / mounted 等)		 同名钩子函数将合并为一个数组，都会被依次调用。 Mixin 钩子先执行，组件钩子后执行
值为对象的选项
(methods / computed / components)		 合并为一个对象。当键名存在冲突时： 以组件自身的方法/计算属性优先
⚠️ 思考：为什么 Vue 3 要用 Composition API（组合式 API）取代 Mixin？
  • 来源不清晰：如果一个组件混入了 3 个 mixin，模板里用了一个 name 或 fetchData()，根本看不出它来自哪个 mixin。
  • 命名冲突：两个 mixin 中如果不小心声明了同名变量或方法，会发生覆盖，引发难以排查的 Bug。
  • 缺乏明确的输入输出契约：很难向 mixin 动态传参或获取精确的返回值。
