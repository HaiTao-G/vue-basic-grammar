01 - Vue 生命周期的四大阶段与八大钩子函数

💡 什么是 Vue 实例生命周期？
一个 Vue 实例从创建（new Vue）、数据初始化、模板编译与挂载 DOM、数据更新重新渲染，到最终销毁解绑的全过程，称为生命周期。
在这个过程中，Vue 提供了 8 个关键钩子函数（成对出现），允许我们在特定时间节点注入自己的业务逻辑。

🚨 致命避坑：为什么绝对不能在 updated / beforeUpdate 中修改自身的响应式数据？
因为数据改变 ➜ 触发 updated ➜ 如果在 updated 里又修改 data ➜ 又会触发新的 update ➜ 导致无限递归死循环更新（Infinite Loop），浏览器标签页会瞬间占满 CPU 假死崩溃！所以日志输出必须与 Vue 响应式状态解耦。

📖 四大阶段核心状态对比表

阶段 钩子函数 此时 data 的状态 此时 $el (DOM) 的状态 关键业务应用
1. 创建阶段
(Creation)		 beforeCreate ❌ 未初始化（undefined） ❌ 未挂载（undefined） 常用于框架底层插件初始化
created ✅ 已完成响应式注入 ❌ 模板未编译，无真实 DOM 最早可发 ajax 请求、取 data
2. 挂载阶段
(Mounting)		 beforeMount ✅ 正常访问 ⚠️ 虚拟 DOM 准备就绪，真实 DOM 未生成 最后修改数据的机会，很少使用
mounted ✅ 正常访问 ✅ 真实 DOM 已经渲染挂载 可操作 DOM、初始化 echarts/swiper
3. 更新阶段
(Updating)		 beforeUpdate ✅ 数据已是最新值 ⚠️ DOM 还是旧值（未重新打补丁） 更新前访问现有的旧 DOM
updated ✅ 数据为最新值 ✅ DOM 已重新渲染打补丁 避免在此修改 data，否则可能死循环
4. 销毁阶段
(Destruction)		 beforeDestroy ✅ 实例与数据仍然完全可用 ✅ DOM 依然存在 清理定时器、解绑 window 事件
destroyed ⚠️ 失去响应式能力 ⚠️ 原生 DOM 脱离 Vue 控制 所有子组件已销毁，指令已解绑
