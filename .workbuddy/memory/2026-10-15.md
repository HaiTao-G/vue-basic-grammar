## 新建「07-状态管理-vuex与pinia」学习目录

- 另一个坑：Vuex 3 的 UMD **会自动安装**（源码里有 `if (!Vue && window.Vue) install(window.Vue)`），示例里不能再写 `Vue.use(Vuex)`，否则报 already installed。
- 内容：`README.md` + 6 个 HTML
  - `01-Vuex入门-state与getters.html`：两个兄弟组件共享一份数据，$store 读取
  - `02-Vuex-mutations与actions.html`：commit / dispatch、同步 vs 异步、strict 模式直接改 state 的报错演示
  - `03-Vuex-辅助函数与模块.html`：mapState/mapGetters/mapMutations/mapActions、cart 命名空间模块 + createNamespacedHelpers
  - `04-Pinia入门-state与getters.html`：defineStore 选项式/组合式两种写法、子组件 setup() 使用、storeToRefs 坑
  - `05-Pinia-actions与异步.html`：待办清单、async action、$patch、$reset、$subscribe（在 setup 里用 Vue.ref 定义日志）
  - `06-Vuex与Pinia对比与选型.html`：同一计数器两套实现并排运行 + 逐项对比表 + 选型建议
- 验证：语法检查通过；headless 渲染 6 页全部正常无 warn；确认 storeToRefs 解构、getters 计算、Vuex/Pinia 双 store 并存都工作。
